# Specification model reference

Generated by `python scripts/generate-model/generate.py` from [the canonical LinkML model](../../../model/dotspec.yaml). Do not edit this file.

Experimental first-class metamodel for source-backed specification snapshots. The exported model is distinct from Markdown authoring checks. Source fidelity, syntax interpretation, named domain mapping, and optional structured decomposition are separate concerns. Existing prose is valid domain content; fields and relationships are populated only by explicit syntax or a declared mapping rule, never by unrecorded NLP inference. Raw source alone does not establish domain coverage.

Model version: `0.9.0-draft`. JSON representation version: `0.1.0`.

The [JSON Schema](../../../model/generated/schema.json) checks local shape. The [runtime catalog](../../../model/generated/catalog.json) supplies inherited class membership, typed reference ranges and ordered slots for graph checks.

See the [relationship reference](relationships.md) for scopes, inverses, cycle policies and assertion projections.

## Model constraints

Identifier uniqueness; referential integrity and typed endpoints; containment ownership and cycle rules; source-byte digest, offset-map and span fidelity; ordered syntax-tree and membership consistency; complete content-binding accounting; scope and resolution consistency; owner-local attribute identity/subattribute_of cycles; paired quality attribute declarations and section content; honest optional decomposition; assertion provenance and consistency are explicit graph checks, not implied by JSON Schema generation.

### ParseStatus

Syntax or frontmatter parse state, independent of domain decomposition.

| Value | Meaning |
| --- | --- |
| `parsed` | Supported syntax parsed; opaque unsupported syntax may still exist. |
| `partial` | Some syntax parsed and some malformed or uninterpreted. |
| `failed` | Parsing failed; original bytes and opaque content remain available. |
| `not_attempted` | No syntax parse attempted. |

### PayloadStorage

Where the exact original bytes can be recovered.

| Value | Meaning |
| --- | --- |
| `inline_base64` | bytes_base64 stores original bytes including BOM and line endings. |
| `external` | An immutable payload locator plus digest addresses original bytes; a mutable repository path alone is insufficient. |

### Presence

Presence of an authored field; omission of the containing slot means absent.

| Value | Meaning |
| --- | --- |
| `empty` | The field or section is explicitly present without body content. |
| `authored` | The field contains authored content, including placeholders or unknown statements. |

### ReadStatus

Whether original source bytes were acquired.

| Value | Meaning |
| --- | --- |
| `read` | Original bytes acquired. |
| `failed` | Read attempted but failed; diagnostic retained. |
| `not_attempted` | Source discovered but not read. |

### ReferenceTraversalMode

Which authored reference edges are inspected.

| Value | Meaning |
| --- | --- |
| `none` | Do not follow references. |
| `direct` | Follow one edge from selected documents and consulted context. |
| `transitive` | Traverse multiple edges under explicit limits; not current dotspec behavior. |

### ResolutionStatus

Resolution results, not extraction/decomposition states.

| Value | Meaning |
| --- | --- |
| `resolved` | Exactly one inspected target identified. |
| `unresolved` | An authored target was recognized but not found. |
| `undefined_label` | A reference-style label lacks a definition, or a system's declared quality attributes lack the authored member label. |
| `unbound_label` | A recognized semantic label has no governing quality attribute declaration. |
| `ambiguous` | More than one target matches. |
| `external` | Target is external and has not been inspected. |
| `out_of_scope` | Target is known to be outside this snapshot scope. |
| `not_attempted` | Resolution has not been attempted. |
