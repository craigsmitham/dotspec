# Specification model reference

Generated by `python scripts/generate-model/generate.py` from [the canonical LinkML model](../../../model/metamodel.yaml). Do not edit this file.

Source-backed specifications and their reader-facing reports. Domain fields retain the authored Markdown through ordered byte ranges. Explicit declarations, links and classification labels supply identity and relationships.

Model version: `0.35.0-draft`. JSON representation version: `0.4.0`.

The [JSON Schema](../../../model/generated/schema.json) checks local shape. The [runtime catalog](../../../model/generated/catalog.json) supplies inherited class membership, typed reference ranges and ordered slots for graph checks.

Read the [model glossary](glossary.md) for definitions of domain terms. See the [relationship reference](relationships.md) for scopes, inverses, cycle policies and assertion projections.

## Model constraints

The validator checks record identity, source range bounds and ownership, declaration membership, typed endpoints, resolution status, classification scope and relationship cycles.

### CompanionRole

How a companion relates to the specification that declares it.

| Value | Meaning |
| --- | --- |
| `formalizes` | States the specification more precisely and must preserve its meaning, such as a formal model property or a schema definition. Normative. |
| `illustrates` | Concrete cases that are part of the specification, such as executable examples. Normative. |
| `verifies` | A procedure for assessing the specification, such as a test suite or manual protocol. A source of evidence; its observations are recorded separately. |
| `explains` | Background, rationale or design explanation. Informative. |
