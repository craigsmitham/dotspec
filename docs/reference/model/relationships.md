# Model relationships

Generated from [the canonical model](../../../model/metamodel.yaml). Do not edit this file.

Model `0.30.0-draft`. This lookup covers every record-reference field, including inherited endpoint refinements. Unchanged inherited fields are documented on their base class. Embedded values and their fields remain in the [complete reference](index.md).

Reverse navigation is derived from declared relationships.

In the model source a field states its category and only what differs from it. Scope, cycle policy and basis default from the category; an unstated inverse is none, an unstated label is the field name, and unstated ordering follows the field shape. This reference shows the completed contract.

Cardinalities describe snapshots, including unfinished declarations. An optional resolved target does not mean a complete authored design can omit the definition it needs. Required list presence does not imply a nonempty list. Ordering preserves authored presentation unless a field explicitly says otherwise; it does not impose execution order. Cycle policies apply to the named relationship, not the entire graph: owner/member backlinks are intentionally reciprocal.

Relationship categories describe edges. They are independent of the core/supporting/generic classifications of model subsets.
