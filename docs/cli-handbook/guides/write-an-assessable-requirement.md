# Write an assessable requirement

From the owning system or component directory, run `dotspec requirement init preserve-entries`, choosing a slug for your requirement. In the new `*.requirement.spec.md` file, use **Statement** for one behavior or property the system must provide. Use **Rationale** for the need or decision that makes it necessary. Link to a governing policy, use case or other source where it explains the commitment. [What makes a requirement assessable?](../explanations/requirements.md).

Under **Applies to**, identify the subject and the circumstances in which the promise holds. Consider what changes the answer, such as operating conditions, workload, population or exclusions. The To-do restart promise covers acknowledged changes on functioning local storage. A request still awaiting acknowledgement falls outside that promise. [Restart conditions](../../../examples/todo/specs/requirements/restart.requirement.spec.md#applies-to).

Try one case that would meet the statement and one that would violate it. If a comparison needs explanation, give the satisfaction rule under **Criterion**. For a measured requirement, use **Measure** for what to observe and how to count or calculate it, and **Target** for the acceptable value or range. State each bound once or reference its authoritative source. When the bound is undecided, record the open decision and who can resolve it. A qualitative rule can identify the required outcome in words. [Worked measure and target](../../../examples/todo/specs/requirements/restart.requirement.spec.md#criterion).

If the requirement classifies a quality, use an attribute ID declared for its specification system. Link to examples or tests that exercise the promise and explain which observations matter. From the same directory, run `dotspec requirement check preserve-entries` with your requirement's slug. Review the findings, then ask someone to judge the two cases using just the requirement. Different answers identify terms or conditions to revisit. [Define a system quality attribute](define-a-system-quality-attribute.md).
