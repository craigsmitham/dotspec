Browse the [full handbook](https://github.com/dotspec-md/dotspec/blob/main/docs/cli-handbook/README.md) for business rules, capabilities, components, features, quality models, and use cases. For the commands used in the quickstart, see [init](/cli/init), [new requirement](/cli/new-requirement), [build](/cli/build), and [check](/cli/check). The [full CLI reference](https://github.com/dotspec-md/dotspec/blob/main/docs/reference/cli.md) lists commands and flags.

To find a guide from the terminal, run `dotspec docs job` or search by phrase with `dotspec docs success criteria`.
