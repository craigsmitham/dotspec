# dotspec

Write, check, and build software requirements in Markdown. Run the alpha CLI with
`npx dotspec@alpha --version` or install it with `npm install --global dotspec@alpha`.
For a repeatable build, substitute the exact version for `alpha`.

Run `dotspec docs` to open the embedded handbook. This package includes the
native executables for macOS, Linux, and Windows on x64 and arm64.

[Project and quick start](https://github.com/dotspec-md/dotspec)
