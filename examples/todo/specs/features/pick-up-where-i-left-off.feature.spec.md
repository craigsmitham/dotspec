# Pick up where I left off

## Description

Find an errand after a break, see whether a reply needs chasing and take up the work again when an answer arrives.

## Purpose

Someone can finish making calls for the day while still owing several results. When they return, the saved reply and follow-up day let them choose whom to contact first. [Follow-up review](../capabilities/follow-up-review.capability.spec.md) enables that choice.

## Groups

- [Return to my list](../use-cases/resume-list.use-case.spec.md) follows one errand through a break and a reply.
- [Show which replies need follow-up](../requirements/follow-up.requirement.spec.md) specifies the cue for deciding where to act.
- [Preserve tasks across restart](../requirements/restart.requirement.spec.md) covers returning after the service itself has stopped.
